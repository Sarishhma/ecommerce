# Bijeshwori mala Traders

Bijeshwori mala Traders is an e-commerce website built for a Nepal-based family
business that sells handcrafted goods — home décor, singing bowls,
jewelry, wooden crafts, felt products, and traditional clothing — from
their stores in Thamel and Boudha, Kathmandu.

The site includes a full customer storefront (product browsing, cart,
wishlist, search, order tracking, user accounts) and a separate admin
panel for managing products and orders.

## Tech Stack

**Frontend**
- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

**State & Data**
- Redux Toolkit
- TanStack Query
- React Hook Form + Zod

**Tooling**
- React Router
- Axios

## Features

- Product browsing with category, price, and search filters
- Product detail pages with image galleries
- Cart and wishlist
- User authentication (login, signup, account management)
- Order history and order tracking
- Newsletter signup and wholesale inquiry forms
- Admin panel for product and order management

## Skills Demonstrated

- Component-driven frontend architecture (feature-based folder structure)
- State management with Redux Toolkit and server-state caching with
  TanStack Query
- Form handling and validation with React Hook Form + Zod
- Responsive, accessible UI design with Tailwind and shadcn/ui
- API integration patterns designed for a mock-to-production workflow
- TypeScript for type-safe, maintainable code
